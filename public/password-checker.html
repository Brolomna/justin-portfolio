Honest note: entropy here is a rough estimate (character pool ^ length). This is a learning demo, not a security guarantee or breach check. Real-world strength also depends on patterns, leaks and reuse, which a simple page can't fully judge. A long passphrase you don't reuse beats a clever short password.

GENERATE A PASSWORD

Random characters from your browser's cryptographic random source. Use a unique password for each account and save it in a password manager.

Choose your options, then generate.

How it works: the checker uses simple length, variety and pattern rules. The generator uses crypto.getRandomValues with rejection sampling to avoid modulo bias, includes each selected character group, then shuffles with the same random source. No network calls, analytics or saved history. Copying puts the result on your device clipboard; treat it as sensitive.
