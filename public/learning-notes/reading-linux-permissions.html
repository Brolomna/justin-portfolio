REFERENCE NOTE

Read the permissions before changing them.

A compact guide to owner, group, others, and rwx. Useful basics without making chmod 777 the default answer.

PermissionsLinuxrwx
By JustinNote added Nov 12, 20263 min read
WHAT THIS NOTE IS BASED ONLinux permissions is one of the topics I marked as covered in my Loadout. Ownership management and users/groups are still learning areas for me. This note stays with the basic permission bits; it is not a privilege-escalation write-up.

Read one group at a time

ILLUSTRATIVE PERMISSION STRING
-rw-r-----
 │  │  └── others: no permissions
 │  └───── group: read
 └──────── owner: read and write

For a regular file, the leading dash is the file type marker. The next nine positions are three groups of read, write, and execute bits: owner, group, and others. A dash in a group means that bit is not set.

What the letters mean

  • r (4): read file contents. For a directory, list its entries.
  • w (2): modify file contents. For a directory, change its entries, subject to other permissions and rules.
  • x (1): execute a file when the file format and system allow it. For a directory, search or traverse it.
FILES AND DIRECTORIES DIFFERDirectory permissions control access to entries, not simply the same operations as file permissions. Deleting a file depends on its containing directory and other rules; a file's own write bit is not the whole story.

Make the smallest intended change

Use a file you own in a disposable practice directory. Inspect it first; don't apply recursive permission changes to system paths to make an error disappear.

SHELL / PRACTICE FILE ONLY
ls -l ./practice.txt
chmod u+rw,go-rwx ./practice.txt
ls -l ./practice.txt

The symbolic mode adds owner read/write and removes read/write/execute from group and others. It deliberately leaves any existing owner execute bit unchanged. For an ordinary practice file where the intended basic mode is exactly owner read/write only, chmod 600 ./practice.txt expresses that mode.

NUMERIC MODE / ORDINARY PRACTICE FILE
chmod 600 ./practice.txt
# owner: 4 + 2 = 6   group: 0   others: 0

The edge of this note

Basic rwx bits are not a full explanation of access. ACLs, ownership, directory traversal, sticky/set-ID bits, mount options, and security policies can change the result. Understanding users and groups better is part of what I am still learning.

This is a reference example, not evidence that I solved a particular machine or changed a real system. Use the manual when the situation goes beyond these basics.
