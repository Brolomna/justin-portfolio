Justin's concept: the terminal is the controller, the 3D world is the visual explanation. This test page is separate from the portfolio's existing learning pages.
Only an allowlisted in-browser interpreter runs. No real shell, server files, accounts, analytics or saved progress. Refreshing starts over. Hidden dot names are not encrypted or protected.
Keyboard: Tab to the command input; Enter runs it; Up/Down recall history. Text is selectable. The world never needs mouse navigation. Motion can be reduced without losing any command behavior.
Reduced-motion preference is respected. If WebGL or the 3D library fails, the live text map and every lesson remain usable.
Commands model the basic Linux concepts, not every shell feature. Options are limited; pipes, redirects, expansion and scripts are not supported. Ubuntu beginner reference.
