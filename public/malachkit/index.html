What does a checksum tell me?

A checksum is a fixed-length fingerprint of file bytes. Identical files produce identical SHA-256 hashes. A mismatch means the bytes differ; a match is only as trustworthy as the source of your expected checksum. Hashing alone does not prove that a file is safe.

Works in a secure context (HTTPS or localhost) with Web Crypto. No file contents or checksums are saved by MalachKit.

Do not paste production tokens or secrets into untrusted environments. Token contents may contain sensitive information.

How to read these results
This inspector supports compact three-segment JWTs with JSON object headers and payloads. It accepts Base64URL with omitted or correct padding and decodes JSON as UTF-8. Encrypted five-segment tokens are not supported.
exp, nbf, and iat are Unix timestamps in seconds. Times shown use your device clock and timezone; a time check does not establish validity for any service. Claims are untrusted, even if a token is structurally readable. Sensitive inputs and results are cleared when you leave this tool or the page.

What is CIDR?
An IPv4 address has 32 bits. The CIDR prefix tells you how many belong to the network. The remaining bits define the address range. NetCalc uses BigInt integer arithmetic to avoid signed 32-bit overflow.
Ordinary subnets reserve network and broadcast addresses. A /31 has two usable addresses only on a point-to-point link (RFC 3021). A /32 represents one host route. These calculations describe address ranges, not device reachability or network configuration.




BUILT TO UNDERSTAND
A practical kit, not a black box.
MalachKit brings three everyday technical tasks into one small browser workbench. It was built as a portfolio project to practice JavaScript, file handling, cryptographic APIs, token formats, and networking fundamentals.
Small by choice
HTML, CSS, and native JavaScript modules. Web Crypto for SHA-256, the File API for local reads, Base64URL and UTF-8 decoding for JWTs, and BigInt for IPv4 arithmetic. No packages, accounts, backend, or external APIs are needed.
Private by default
Inputs stay in memory on this device. MalachKit does not store input history, transmit your inputs, log tokens, or use analytics. Clipboard and downloaded files are controlled by your browser and device. Only the app's own static assets are loaded.
Know the limits
Files are capped at 50 MB because hashing is not streaming. JWT signatures are never verified. Subnet calculations are IPv4-only and do not scan or contact any network. Device time is used for JWT timestamp checks.
