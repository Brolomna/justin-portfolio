Inside a simulated machine
The terminal is the controller; the 3D world is the visual explanation. This page teaches basic Linux filesystem navigation using an in-browser simulation.
Only a small allowlist of commands is implemented. No real shell is executed, no server files are exposed, and no account or learning progress is stored. Hidden dotfiles are not encrypted; they are simply omitted from a normal listing.
